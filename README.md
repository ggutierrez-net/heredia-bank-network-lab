# Heredia Bank – Enterprise Network Lab

A hands-on lab simulating the network of a bank with a headquarters, two branches and a data center. I'm building it step by step to practice the skills used in real network operations and support roles.

## Goals
- Design a segmented network (VLANs for tellers, employees, cameras and guests)
- Route between sites with OSPF, NAT and firewall rules (ACLs)
- Run Windows Server (Active Directory) and Linux servers
- Monitor devices and servers with Splunk dashboards and alerts
- Automate health checks with Python and Bash
- Back up and restore servers and run a disaster recovery drill
- Document incidents with tickets, runbooks and post-mortems

## Tools
Cisco Packet Tracer · VirtualBox · Windows Server · Linux · Splunk · Python · Bash · Wireshark
